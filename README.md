# CIEA

Website for the Caribbean International Education Agency. Plain HTML, CSS and a little JavaScript. No build tools needed: open `index.html` in a browser, or upload the folder to any static host (Netlify, GitHub Pages, Vercel, cPanel).

## Pages

`index.html` (Home), `about.html`, `study-in-barbados.html`, `programs.html`, `course-finder.html`, `services.html`, `contact.html`. Shared styles and scripts live in `assets/`.

## Adding your photos

Every photo spot is a striped box marked **Photo placeholder** with a note describing the suggested image. To swap one in, replace the placeholder `<div class="ph" ...>...</div>` with:

```html
<img src="assets/photos/your-photo.jpg" alt="Describe the photo">
```

The image fills the rounded photo frame automatically.

## Editing content

The pages are generated by `build.py` from shared header, footer and content blocks. Edit text there and run `python3 build.py`, or edit the HTML files directly if you prefer (then stop using the script, or it will overwrite your edits).

## Course finder

`course-finder.html` lists every UWI Cave Hill programme from `data/uwi-cave-hill-courses.csv`. Open the CSV in Excel or Google Sheets to add, remove or fix a programme (one row each: institution, level, award, programme, faculty, notes, extra search keywords, link), save it as CSV, then run `python3 build.py`. The list was taken from UWI Cave Hill's undergraduate guide (December 2025) and postgraduate guide (February 2026); check UWI's site each year for changes.
